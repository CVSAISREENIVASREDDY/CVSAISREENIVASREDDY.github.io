RAG · Distributed Systems↗

Web-RAG Engine

A scalable retrieval-augmented generation platform that asynchronously ingests, indexes, and answers questions about any web content. Submit a URL → Celery workers (backed by Redis) fetch, clean, chunk and embed it with MiniLM-L6-v2 (384-d) into ChromaDB, while PostgreSQL tracks every ingestion job. Queries are semantically embedded, top-k chunks retrieved, and Groq Llama-3 generates fact-grounded answers with sources. Fully containerized with Docker Compose.
